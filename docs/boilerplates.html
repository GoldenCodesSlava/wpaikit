PrinciplesПринципыPrincipii

  • All custom code lives in the theme. Core and third-party plugins are not edited.Весь свой код — только в теме. Ядро и сторонние плагины не правятся.Tot codul propriu stă în temă. Nucleul și plugin-urile terțe nu se modifică.
  • Controllers render routes, services hold logic, Twig only displays.Контроллеры рендерят маршруты, сервисы держат логику, Twig только отображает.Controllerele randează rutele, serviciile țin logica, Twig doar afișează.
  • No queries or formatting in Twig; Twig autoescape stays on.Никаких запросов и форматирования в Twig; autoescape Twig всегда включён.Fără interogări sau formatare în Twig; autoescape-ul Twig rămâne activ.
  • Every block is a triplet: PHP class + Twig view + ACF JSON.Каждый блок — тройка: PHP-класс + Twig-шаблон + ACF JSON.Fiecare bloc este un triplet: clasă PHP + view Twig + ACF JSON.
  • Styles are BEM + Tailwind via @apply, mobile-first.Стили — BEM + Tailwind через @apply, mobile-first.Stilurile sunt BEM + Tailwind prin @apply, mobile-first.
  • Local state goes into wp-config.php, never into theme files.Локальные настройки — в wp-config.php, а не в файлах темы.Starea locală merge în wp-config.php, nu în fișierele temei.
