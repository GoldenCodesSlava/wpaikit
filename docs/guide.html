Knowledge is the set of slash commands, prompts, skills and rules that the AI assistant reads. It is installed into the current folder (or into the project root if a parent folder contains .wpaikit.json). Knowledge — это slash-команды, prompts, skills и правила, которые читает AI-ассистент. How packs are selectedКак выбираются наборыCum se aleg pachetele

  • Without --packs, the first install asks: All or Choose packs. Without an interactive terminal (CI), everything is installed. Без --packs при первой установке CLI спросит: All или Choose packs. Без интерактивного терминала (CI) ставится всё. Fără --packs, prima instalare întreabă: All sau Choose packs. Fără terminal interactiv (CI) se instalează tot.
  • Running again without flags reuses the selection from .wpaikit/knowledge-manifest.json — that is how you update. Повторный запуск без флагов берёт выбор из .wpaikit/knowledge-manifest.json — это и есть обновление. Rularea repetată fără flaguri folosește selecția din .wpaikit/knowledge-manifest.json — așa se face actualizarea.
  • Packs can be combined: --packs design,slicing. Наборы комбинируются: --packs design,slicing. Pachetele se pot combina: --packs design,slicing.
  • The WordPress profile (standard / woo) is only asked for the WordPress pack. If the project has .wpaikit.json, the profile comes from there. Профиль WordPress (standard / woo) спрашивается только для набора WordPress. Если в проекте есть .wpaikit.json, профиль берётся оттуда. Profilul WordPress (standard / woo) se cere doar pentru pachetul WordPress. Dacă proiectul are .wpaikit.json, profilul se ia de acolo.

FAQ

«Knowledge installation stopped to protect local files»

WPAIKit files in the project were edited by hand. Move your edits into .wpaikit/project.md and run with --force, or delete the changed files — the CLI recreates them. Файлы WPAIKit в проекте менялись вручную. Перенесите свои правки в .wpaikit/project.md и запустите с --force, либо удалите изменённые файлы — CLI создаст их заново. Fișierele WPAIKit din proiect au fost modificate manual. Mută modificările în .wpaikit/project.md și rulează cu --force, sau șterge fișierele modificate — CLI-ul le recreează.

How do I change packs?Как сменить набор?Cum schimb pachetele?

Run install with the new list, e.g. --packs design,slicing. Files of removed packs are deleted. Check the list with --dry-run first. Запустите install с новым списком, например --packs design,slicing. Файлы снятых наборов будут удалены. Сначала проверьте список через --dry-run. Rulează install cu lista nouă, de exemplu --packs design,slicing. Fișierele pachetelor scoase se șterg. Verifică întâi lista cu --dry-run.

«--wp-profile requires the WordPress pack»

The WordPress profile only makes sense with the WordPress pack: add wordpress to --packs. Профиль WordPress имеет смысл только с набором WordPress: добавьте wordpress в --packs. Profilul WordPress are sens doar cu pachetul WordPress: adaugă wordpress în --packs.

«does not match .wpaikit.json preset»

The project already records a preset (standard or woo). Drop --wp-profile — the profile is read from .wpaikit.json. В проекте уже записан preset (standard или woo). Уберите --wp-profile — профиль возьмётся из .wpaikit.json. Proiectul are deja un preset salvat (standard sau woo). Renunță la --wp-profile — profilul se citește din .wpaikit.json.

Slash commands don't show up in Claude CodeSlash-команды не появились в Claude CodeComenzile slash nu apar în Claude Code

Start Claude Code from the folder that contains .claude/commands/ (the project root) and restart the session after installing. Запускайте Claude Code из папки, где лежит .claude/commands/ (корень проекта), и перезапустите сессию после установки. Pornește Claude Code din folderul care conține .claude/commands/ (rădăcina proiectului) și repornește sesiunea după instalare.
