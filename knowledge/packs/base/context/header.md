# wpaikit Knowledge

This file is the entry point for AI tools (Claude Code, Codex, Cursor, etc.) working on a project
that uses the wpaikit knowledge base.

Installed packs: {{packs}}.
The installed packs and file checksums are stored in `.wpaikit/knowledge-manifest.json`.
Re-run `wpaikit knowledge install` to repair or update them, or `wpaikit knowledge install --packs <list>`
to change the selection.

Read the relevant file from `knowledge/` before acting on any wpaikit-related task.
When the user writes `/command-name [args]`, read the linked prompt file and follow it exactly.
